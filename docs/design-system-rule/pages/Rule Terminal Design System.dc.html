ds-next · terminal design system · Modernist direction · Rule

The grid shows.
One red, strong rules, nothing rounded.

The Modernist design system translated to a terminal. Every turn opens with a numbered 2px rule; the input is a heavy square box pinned to the bottom; the agent speaks from a red square, tools from an ink one; results and folds align under them on a three-column grid. Red is the only colour and it means needs you — the prompt, the focused option, a failure. Everything else is ink on ground. Same modern shape as Canopy (pinned footing, folded thinking, numbered dialogs); different grammar. Screens in Rule Screens; tokens in rule/tokens.json, code in rule/code/ui_style.py.

Assumptions
SourceModernist tokens: neutral ramp for the greys, accent-500/400 (dark) and accent/accent-700 (light) for red. No green, no yellow. StackRich prints the transcript; prompt_toolkit owns the footing. No alt-buffer. RulesHeavy box-drawing (━ ┃ ┏ ┓) is the terminal's 2px divider. Light lines are not used. Width80 columns; rules, box and status row stretch to the real width.

2Principles

The grid shows

Three columns — 1 for glyphs, 3 for what is said or run, 5 for what came back — and a label column at 12. Values land in the same place on every screen so the eye reads down, not across.

Rules divide

Every prompt opens with a full-width heavy rule carrying the turn number flush left. Turns are addressable; the transcript reads as a ruled page. Nothing else draws horizontal lines.

One red, and it means you

Red is for the prompt glyph, the focused option, a failure, a warning. The agent's square is red because its words are addressed to you. Done is ink — success doesn't need a colour.

Nothing rounded

The input box and dialogs are heavy square frames. Squares (■ ▪ ▫ □) are the markers. The spinner is a rotating quadrant.

Flush left, always

Titles sit at the left end of a rule, labels at the left of their column, option numbers before their text. Nothing is centred — not the banner, not a dialog question.

The footing never moves

Heavy box + bare status row, redrawn in place; everything above is append-only scrollback.

Thinking is quiet

Reasoning streams in dim with a · lead, then folds to · Thought for 3s ctrl-o. No italics — Modernist doesn't slant.

Facts, not sentences

Results are terse columns: +14 −1, 13 passed 1.42s, 3 tools 15.2s $0.0041. Two spaces between facts; no separators.

3Colour roles

Eight roles, both from Modernist's ramps. The dark theme inverts the page: ground = Modernist text (#201e1d), text = Modernist ground. Red steps up to accent-500 on dark and uses accent-400 for text-size runs; on light it is the accent itself with accent-700 for text. There is no ok/warn/err triad: done is text, warn and err are red (err bold).

8Motion

Redraw only the footing

Box, popup and status row are the only repainted rows. The transcript above is written once.

One live line, then it lands

▘ Drafting 4s esc interrupts sits above the box; when the step finishes, the message replaces it in place — the ▪ lands where the ▘ was.

Thinking folds

Dim lines collapse to · Thought for 3s ctrl-o. ctrl-o reopens the last fold.

Quadrant tempo

▖▘▝▗ at 6 fps — a square turning, never a spinner's circle. Verb changes per step; seconds tick once a second.

Popup, not page

/ opens a list under the box; ■ marks the focus; tab completes.

Dialogs replace the box

The frame edge goes red; the status row carries its keys; the answer prints as a flat line and the box returns.

Spinner verbs — drafting-room and river: Drafting · Ruling · Measuring · Squaring · Aligning · Plotting · Setting · Composing · Inking · Paddling · Portaging · Sounding · Charting. Tool runs may pass an explicit verb (Running tests).
