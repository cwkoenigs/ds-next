Observed: three glyph families compete (◆ → │ in turns, ❯ ‹› in widgets, box panels for banner/approval); the toolbar repeats the repo name; result lines truncate to one line with no way to open them; the form's label column (17 cols) and the turn's indent (2 cols) don't align. The design system in ds-next Terminal Design System starts from these.
